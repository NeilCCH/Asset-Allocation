# 測試清單(保險箱 / 本機)

逐項勾選走過,確認功能正常。有問題記下畫面或錯誤訊息。

## 0. 前置

- [ ] Mac 的 dev server 有開著(終端機 `npm run dev`,或由協作 session 啟動)
- [ ] Supabase 的 **Confirm email 已關閉**(測試時免收信)
- **開啟網址:**
  - 電腦(Mac):`http://localhost:3100`
  - 手機 / 平板(需與 Mac 同一 Wi-Fi):`http://192.168.2.95:3100`
    - ⚠️ IP 可能變動;若打不開,在 Mac 終端機跑 `ipconfig getifaddr en0` 重新查

---

## A. 顧問流程(先做,才能產生邀請連結)

1. 開 `/advisor` → 切「註冊」
   - [ ] 填 Email、密碼、**姓名**、**手機**
   - [ ] 上傳**名片正面 + 反面**(兩張都要)
   - [ ] 勾**證照**並填**合格證號**(外幣/投資型免證號)
   - [ ] 按「註冊並建立檔案」→ 成功進入後台
2. 後台檢查
   - [ ] 顯示你的姓名、證照(含證號)
   - [ ] 有**專屬推薦碼**
   - [ ] 「邀請客戶」卡片有連結 + **複製連結**鈕
3. [ ] 複製邀請連結(等下客戶用)

> 也可用先前註冊的帳號(neo0935)登入,但姓名/名片是空的;要看完整效果請用新 Email 註冊一個。

---

## B. 客戶流程(用 A 複製的邀請連結)

1. [ ] 開邀請連結 → 顯示「您由財富管理顧問(推薦碼 …)邀請」
2. [ ] 按「開始資產健檢」
3. [ ] **個資同意**:條文完整(個資法七項)→ 勾同意 → 下一步
4. [ ] 填**基本 · 家庭**(姓氏、稱謂、年齡、退休年齡、子女…)
5. [ ] 填**收支 · 時間**(收入型態、年收入、月結餘、時間軸、急迫性)
6. [ ] 填**資產盤點**(勾類別 + 填金額)→「看我的資產健檢」
7. 儀表板檢查
   - [ ] 資產總額、流動性、保障型占比
   - [ ] **資產類別分布圓餅圖**
   - [ ] 保障 vs 投資比重
   - [ ] 缺口概況(退休/保障/教育)
8. [ ] 「產出健檢報告」→ 報告完整 → **列印 / 儲存為 PDF**(確認中文不亂碼)
9. [ ] 「建立帳號」→ 註冊 → 之後可登入回看

---

## C. 顧問後台(回到 A 的顧問帳號)

1. [ ] 客戶清單出現剛才 B 的客戶 + **A/B/C 分級**
2. 點進該客戶 → 工作台
   - [ ] 事實層摘要、資產明細
   - [ ] **有效客戶評分**(五因子明細)
   - [ ] **缺口試算**:調整「年報酬率 / 預估餘命…」→ 缺口**即時重算**
   - [ ] 展開「進階參數」(教育金 / 扶養)也能調
   - [ ] 勾選**配置面向**、撰寫**建議** → 按「儲存」→ 顯示「已儲存 ✓」
   - [ ] 「產出報告」→ 報告含**你的建議** + **落款(姓名 + 證照)**

---
